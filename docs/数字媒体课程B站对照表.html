📚 建议学习顺序（结合你的 multimodal-engine 项目）

第一阶段（打地基）：李沐《动手学深度学习》P1-P25 → 理解 PyTorch + CNN，直接能看懂你项目里的 VGG19 代码

第二阶段（图像原理）：杜克大学《数字图像处理》→ 补频域滤波、图像增强等底层知识

第三阶段（视觉进阶）：CS231n → 深入目标检测、生成模型，理解 Stable Diffusion 背后的 CV 理论

第四阶段（图形渲染）：GAMES101 → 补充渲染管线、光栅化、着色等图形学基础

第五阶段（全局整合）：多媒体应用设计师课程 → 把图像/视频/音频串成完整的多媒体技术体系
